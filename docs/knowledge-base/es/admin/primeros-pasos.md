# Primeros Pasos en el Panel de Administracion

## Acceso al Panel

El panel de administracion se encuentra en la ruta `/admin`. Para acceder necesitas:

1. **Credenciales de administrador**: Email y contrasena proporcionados por el equipo de TI.
2. **Rol asignado**: Tu cuenta debe tener el rol `super_admin` o un rol con los permisos necesarios.

## Inicio de Sesion

1. Navega a la URL del panel: `https://tu-dominio.com/admin/login`
2. Ingresa tu correo electronico
3. Ingresa tu contrasena
4. Haz clic en **Entrar**

> Si olvidaste tu contrasena, utiliza el enlace "Olvidaste tu contrasena?" en la pagina de inicio de sesion.

## Navegacion Principal

El panel cuenta con una barra lateral (sidebar) que organiza las secciones:

| Seccion | Descripcion |
|---------|-------------|
| **Dashboard** | Vista general con estadisticas |
| **Proveedores** | Gestion completa de proveedores |
| **Catalogos** | Tipos de proveedor, tipos de documento, estados de documento |
| **Sucursales** | Gestion de sucursales |
| **Administracion** | Roles y permisos del sistema |

## Modo Oscuro

El panel soporta modo oscuro de forma nativa. Puedes alternar entre modo claro y oscuro desde el menu de usuario en la esquina superior derecha.

## Busqueda Global

Utiliza el atajo `Ctrl+K` (o `Cmd+K` en Mac) para abrir la busqueda global. Puedes buscar proveedores, documentos y cualquier recurso del sistema.
