# Proceso de Onboarding

Despues de establecer su contrasena, el proveedor debe completar su perfil empresarial. Este proceso se realiza una sola vez.

## Informacion Solicitada

El formulario de onboarding solicita:

### Datos de la Empresa
- **Razon Social**: Nombre legal de la empresa
- **RFC**: Registro Federal de Contribuyentes (13 caracteres)
- **Telefono**: Numero de contacto principal
- **Tipo de Proveedor**: Seleccion del catalogo

### Direccion
- **Calle y numero**
- **Colonia**
- **Ciudad**
- **Estado**
- **Codigo Postal**
- **Pais**: Mexico, USA o Canada

### Datos Bancarios
- **Banco**: Nombre de la institucion bancaria
- **CLABE Interbancaria**: 18 digitos (unica por proveedor)
- **Titular de la cuenta**: Nombre del titular

## Proceso

1. El proveedor completa todos los campos obligatorios
2. Hace clic en **Completar Onboarding**
3. El sistema valida la informacion
4. Si todo es correcto, el estado cambia a **Perfil Completado**
5. Se ejecuta una verificacion automatica
6. El proveedor es redirigido al **Dashboard**

## Problemas Comunes

| Problema | Solucion |
|----------|----------|
| Error en RFC | Verificar formato: 3-4 letras + 6 digitos fecha + 3 homoclave |
| CLABE ya registrada | Cada CLABE debe ser unica en el sistema |
| No puede seleccionar tipo | Verificar que existan tipos activos en el catalogo |
| Boton deshabilitado | Todos los campos obligatorios deben estar completos |
| Quedo en "Perfil Completado" | La verificacion automatica lo activara pronto |
